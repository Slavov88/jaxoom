## Findings

The simple update, residual, multiple-input, parameter-update, and training-like workloads produced compiler-confirmed opportunities. The shape-mismatch control produced no candidate and no recommendation.

The best focused training-like result was donation of positional arguments `(0, 1)` on RTX 3050 JAX 0.11.0, saving 16,512 compiler-accounted bytes with a 16,640-byte alias gain. This is a small pure-JAX validation case, not a general training benchmark.

Donation of a positional pytree argument refers to the entire positional argument. Eligible array leaves inside that pytree may be donated together.

The CPU 0.11.0 run had one static-compatible single false positive. CPU 0.6.2 and RTX 3050 0.11.0 had no static-compatible single false positives in this focused matrix. These are observations from six workloads, not a general precision guarantee.

## Semantics

- A compiler-confirmed candidate means only that the compiled memory accounting improved for the tested backend and JAX version.
- Donated argument buffers must not be used after the compiled call.
- Caller semantic safety is unknown to this advisor.
- Savings are compiler-accounted memory, not runtime peak memory.
- Calibration intervals are not used in donation savings.

## Reproducibility

All runs used seed 0 and were generated by the same repository commit recorded in each JSON artifact. Runtime smoke tests used fresh copies of inputs and compared baseline and donated outputs.
